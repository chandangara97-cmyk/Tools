Office & Bills
Which entry goes where
• ➕ Add Entry → full-screen step-by-step form (type → dates → places → travel → scheme/location → check & save)
• Tour entry (dates, places, mode, km, fare, scheme, sample unit) → TA/DA range + Diary journey rows in Hindi (शिमला, बड्डी, बस, 125, 280 00); first day = outward, last day = return (reverse places), every tour day gets scheme & sample unit. Tentative Program = Annexure-III replica (Block-I table padded with blank rows to fill page 1, Block-II totals auto-calculated, 3 signature lines); TA/DA sheet prints on one page, padded with blank rows to the bottom with a signature line. Column 11 is left blank for you to type; any cell can be edited directly on the sheet; weekdays auto-show कार्यालय उपस्थित 8:30, Sat/Sun show शनिवार/रविवार अवकाश
• Journey day times → shown in the row just below the date (cols 1 and 3); long work text in col 11 runs line by line down the following rows of the same day; the next date starts below where the text ends
• Diary Journey/Field day → one TA/DA row for that date (and removed if you change the day to Office/Leave)
• Diary Mode (col 5) ↔ TA/DA Mode · Road KM (col 6) ↔ K.M. · Fare Rs + P (cols 7–8) ↔ Total Fare (edit either side)
• Last day of a tour → hotel off in TA/DA
• Designation, 100/70/30% slab, hotel toggle → TA/DA only
• Tentative Program → always for the month AFTER the Diary month (Diary Oct → Program Nov); name & designation come from the TA/DA sheet
• Auto-save → every 15 s under name + designation + Diary month; restored on re-open or when you re-enter the same name & designation
